A5.1 VERIFIED — README `player_client` (master L1861, verbatim): "Clients to extract video data from. ## Corrections that change the design

1. JS runtime is for **format URLs only** (n/sig); subtitles/metadata don't need it. Missing runtime = warning + `web` client dropped (A2.7/A2.8). Node ≥ 22 (already in the image) is a supported runtime → no Deno needed unless you want the sandbox.
2. `web`-client subtitle PO-token requirement is experiment-gated (`exp=xpe|xpv`), not blanket as the wiki table says; when hit, tracks are silently discarded with a stderr warning "…subtitles require a PO Token which was not provided…" (A5.4). Parse for it.
3. "No subtitles" is exit 0 + `[info] There are no subtitles for the requested languages`; bot check/unavailable are exit 1 with YouTube's `playabilityStatus.reason` (+ cookies hint); subtitle 429 is exit 1 `Unable to download video subtitles for 'xx': HTTP Error 429…`. Do not key on "Sign in" (private videos contain it too); key on "not a bot" / "rate-limited" / "IP is likely being blocked" / "HTTP Error 429" (A4).
4. `--ignore-no-formats-error` makes a bot check look like "no captions" unless stderr is parsed (A4.3).
5. youtubei.js does not throw on `LOGIN_REQUIRED`; `getTranscript()` then reports "Video likely has no transcript" — you must check `playability_status` first (B2.5). Its transcript endpoint has an open intermittent-400 issue (B3.2). It needs no jsdom, but `Platform.shim.eval` is user-supplied if you ever decipher formats (B3.4).
6. `yt-dlp_linux` is glibc-only; use `yt-dlp_musllinux` on Alpine or a glibc base. Deno has no musl build; `denoland/deno:alpine` ships its own glibc (A6.1/A8.3).
7. `pip install yt-dlp` without `[default]` installs **no** `yt-dlp-ejs` (A6.2).

## Unverifiable items (and how to resolve)

- Exact YouTube `playabilityStatus.reason` strings (bot check, private, removed) — server-provided; capture from stderr in the field (A4.3/A4.4).
- `{lang} subtitles not available for {video_id}` warning text and the `[:1]` default-language slice — read `YoutubeDL.py` L3183–3200 at the tag locally (`pip download yt-dlp==2026.8.19`) (A3.6/A4.2).
- Top-level `language` in `-J` for YouTube; presence of `requested_subtitles` on stdout — one `-J` run (A3.5/A3.6).
- timedtext URL expiry/IP binding — curl probe (C2.2).
- json3 window fields and full `aAppend` semantics — fixture from the two test videos (C1.2).
- youtubei.js npm publish timestamp; `bgutils-js` as official recommendation; safety of `retrieve_player: false` for transcripts — probe.
- `yt-dlp -U` message inside a pip install (A6.4).
